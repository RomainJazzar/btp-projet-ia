Ce projet est PRÊT à l'emploi. Tous les fichiers sont générés.


┌──────────────────────────────────────────────────────────────┐
│  INSTALLATION AUTOMATIQUE (1 commande)                       │
└──────────────────────────────────────────────────────────────┘

Ouvrir un terminal (cmd ou PowerShell) dans ce dossier et taper :

    install_all.bat

Ce script fait TOUT automatiquement :
  ✓ Crée la structure des dossiers
  ✓ Génère tous les fichiers Python
  ✓ Crée l'environnement virtuel
  ✓ Installe les dépendances
  ✓ Lance les tests
  ✓ Démarre l'application

→ L'application s'ouvre sur http://localhost:8501


┌──────────────────────────────────────────────────────────────┐
│  OU : INSTALLATION MANUELLE (si install_all.bat échoue)      │

│  APRÈS INSTALLATION                                          │
└──────────────────────────────────────────────────────────────┘

L'application Streamlit s'ouvre avec 2 onglets :

📥 INBOX
   • Upload un PDF
   • Métadonnées extraites automatiquement
   • Renommer selon convention : YYYY-MM-DD_TYPE_ENTITE_NUM.pdf
   • Indexation plein texte SQLite FTS5

🔍 RECHERCHE
   • Requête plein texte
   • Résultats avec snippets surlignés
   • Q/R synthétique optionnel
